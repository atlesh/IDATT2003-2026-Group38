<h2>Git branch naming conventions</h2>
View <a href="https://dev.to/varbsan/a-simplified-convention-for-naming-branches-and-commits-in-git-il4"> Git branch naming conventions </a> for a detailed overview.
A branch should be named using the convention `category/reference/description`. 

Categories can be:

- `feature`
- `bugfix`
- `hotfix`
- `test`

References should reference an issue, if no issue is linked use `no-ref`.

Description should be short and sum up the purpose of the branch.
